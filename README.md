# EricOS · Aurora Edition

A polished macOS-inspired personal desktop for Eric.

## Highlights
- Refined glass windows, menu bar and Dock
- Functional red/yellow/green window controls
- Window dragging, focus, minimize, maximize and restore
- Spotlight, Control Center and Notification Center
- Project shortcuts for Chinese, Chemistry and Stillflow
- Music space for Ed Sheeran, Taylor Swift and Coldplay
- Responsive mobile layout and reduced-motion support
